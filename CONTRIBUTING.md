# Contributing

## Commit messages

Semantic commits are required for this repository. Use the Conventional Commits format:

```text
<type>[optional scope]: <description>
```

Common types include:

- `feat`: add or expand functionality
- `fix`: correct a bug
- `test`: add or update tests
- `docs`: documentation-only changes
- `refactor`: code changes without a behavior change
- `chore`: maintenance work

Examples:

```text
feat(review): add investigation notes
fix(sync): preserve Pi-hole sync history
test(ui): cover blocked-domain filtering
docs: document Raspberry Pi deployment
```

Keep the description short, use the imperative mood, and avoid ending it with a full stop.
